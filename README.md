# DeskWatch - 桌面行为监测与标注系统

DeskWatch 是一个基于 Python 的桌面行为检测与数据标注系统。它允许用户连接 RTSP 流或本地摄像头，以设定的时间间隔对桌面进行抓图，并使用 AI 模型实时识别当前的行为（例如：使用电脑、看手机、吃东西、暂离、喝水等）。

该项目提供了一个精美而现代的 Web 仪表盘，支持实时状态监控、可视化行为统计、人工快速审核与纠偏（可作为 CNN 模型的数据集来源）、以及在 UI 端一键启动 ConvNeXt 模型训练的完整闭环。

---

## 🚀 核心功能

1. **多模型推理模式切换**:
   - **CLIP 模式**: 采用轻量且性能强劲的 **MobileCLIP (MobileCLIP2-S0, dfndr2b)** 模型，基于文本与图像的余弦相似度进行零样本 (Zero-shot) 行为识别。通过 `timm` 进行重参数化 (Reparameterization)，大幅优化推理时延与内存占用。
   - **VLM 模式**: 通过 OpenAI 兼容格式的多模态大模型 API（如 GPT-4o-mini 或本地 LLaVA 接口）传递 Base64 画面进行自然语言推理。
   - **CNN 模式**: 载入在本地审查数据集上微调后的轻量化 **ConvNeXt-Tiny** 图像分类模型，提供极低延迟的本地化推理。

2. **背景多线程数据采集**:
   - 后台守护线程周期性抓取视频流。
   - 自动压缩分辨率（最大边长限制为 640 像素），在保障分类精度的前提下极大地缩减了磁盘空间占用。
   - 记录存储于 SQLite 数据库中。

3. **双重统计大屏 (Web UI)**:
   - **行为饼图**: 采用 Chart.js 动态计算各行为累计时长（分钟数），界面极具视觉冲击力。
   - **时间线图谱**: 基于 CSS 渐变色模块，直观合并并渲染今天各时间段的行为时长。

4. **超凡审查标注体验**:
   - 提供快速筛选和显示未审核的抓拍结果。
   - **键盘热键支持**: 按数字键 <kbd>1</kbd> 至 <kbd>9</kbd> 可立即完成当前图片的分类纠错并跳至下一张，提升效率。
   - 被审核更正的图片会自动按类别整理存放至 `data/dataset/<category_name>/` 文件夹，无缝接入训练流。

5. **本地 CNN 微调与自训练**:
   - 可在 Web 界面选择轮数 (Epochs)、批大小 (Batch Size) 与学习率。
   - 后台线程执行微调任务，并通过 API 实时向前端输出训练准确率 (Accuracy)、训练损失 (Loss) 等。

## 📦 环境要求与依赖安装

系统建议使用 **`uv`** 作为 Python 虚拟环境与包管理器，以获得极速的构建体验。

### 1. 快速初始化虚拟环境

在项目根目录下，使用 `uv` 创建并激活虚拟环境：

```bash
# 创建虚拟环境
uv venv

# 激活虚拟环境 (Windows CMD / PowerShell)
.venv\Scripts\activate
```

### 2. 安装全部依赖包

```bash
uv pip -r requirement.txt
```

## ⚡ 运行与操作流程

### 第一步：自检环境与初始化
运行 `verify.py` 脚本，它会自动检测必要的文件是否存在、数据库是否能正常建表、并检测 PyTorch 和 OpenCV 的可用性。

```bash
.venv\Scripts\python verify.py
```

### 第二步：启动 API 与 Web 站点
运行启动文件：

```bash
.venv\Scripts\python -m backend.main
```
系统启动后，后台摄像头服务将**默认开启**。您可以通过浏览器打开：
👉 **[http://localhost:8000](http://localhost:8000)**

### 第三步：连接您的摄像头
1. 访问网页的 **“系统配置”** 面板。
2. 在“摄像头源”文本框中输入连接地址：
   - 如果使用电脑默认网络摄像头，输入 `0`（默认值）。
   - 如果使用局域网监控摄像头，输入 RTSP 流地址，例如：`rtsp://admin:password@192.168.1.100:554/h264`。
3. 选择您使用的分类模式（默认为 CLIP，使用轻量 MobileCLIP 零样本推断）。
4. 点击 **“保存并应用配置”**，系统会热重载摄像头线程。

### 第四步：收集与标注数据集
1. 当摄像头运行一段时间后，转到 **“人工审查”** 面板。
2. 页面中会呈现所有采集的临时图片及其预测类别。
3. 鼠标选择，或在键盘上按下对应的数字键 **<kbd>1</kbd> ~ <kbd>9</kbd>** 快速更正分类。
4. 纠偏更正后的图片会立即归纳进 `data/dataset` 目录。

### 第五步：微调自定义 CNN 并切换
1. 确保每个类别收集了一定数量的样本后，进入 **“模型训练”** 面板。
2. 输入微调参数（例如 Epochs = 10，Learning Rate = 0.0001），点击 **“开始微调”**。
3. 您可以从旁边的控制台窗口实时看到每一轮的损失率和准确度。
4. 训练完毕后，返回 **“系统配置”**，将分类模式切换为 **“自定义 CNN 模型”** 即可体验高帧率、无网络依赖的本地端分类。
